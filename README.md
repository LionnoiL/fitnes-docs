# Інструкція користувача — Система обліку фітнес-центру

Онлайн-версія інструкції для персоналу (ресепшн, продажі, склад, звіти).

📖 **Читати:** https://lionnoil.github.io/fitnes-docs/

Документація організована за функціональними блоками (видати ключ, продати абонемент,
заморозити абонемент тощо) зі скріншотами інтерфейсу та робочими переходами за посиланнями.

> Скріншоти зроблено на демонстраційних (тестових) даних.
